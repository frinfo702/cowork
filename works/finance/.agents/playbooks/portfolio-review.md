# playbook: portfolio-review — 資産の棚卸し

## 目的

すべての口座と資産を 1 枚に集約し、資産クラス・通貨・コスト・口座区分で分類する。判断はしない。次の分析の土台を作る。

## 手順

1. 口座を網羅する。銀行、証券、iDeCo、保険、ポイント、不動産、ローン (負債も資産の一部)。
2. データを集める。残高、銘柄、取得額、評価額、口座区分 (特定/一般/NISA/iDeCo)、通貨。
   - 明細 CSV や PDF があれば `xlsx` / `pdf` skill で読み取る。大量処理はサブエージェントに委任する。
   - 手入力の場合は `data/` にテンプレートを作って記録する。
3. 資産クラスに分類する。現金・預金 / 国内債券 / 海外債券 / 国内株式 / 海外株式 / REIT / コモディティ / 暗号資産 / 保険・年金 / その他。
4. 集計する (`skills/portfolio-analysis`)。
   - 資産クラス別比率、通貨別比率、口座区分別比率
   - 負債を差し引いた純資産
   - 年間コスト (信託報酬、手数料、保険料) と資産比
   - 生活防衛資金として使える流動性
5. 事実だけを報告する。良い/悪いの評価はユーザーが求めたときだけ、基準を明示して行う。
6. スナップショットを `data/` に保存する。ファイル名に基準日を入れる (例: `data/portfolio-2026-09-18.xlsx`)。

## 使う skills

- `skills/portfolio-analysis`
- `skills/fee-and-cost-audit`
- `skills/evidence-and-disclosure`

## 出力

- 資産一覧表 (口座、銘柄、資産クラス、評価額、比率、コスト)
- サマリ (純資産、資産クラス比率、通貨比率、年間コスト、流動性)
- データの欠けている項目と、次に確認すべきこと

## 承認・エスカレーション

`approval: none`。個人データは `data/` のみ。会話ログに残高を大量に貼らない。
