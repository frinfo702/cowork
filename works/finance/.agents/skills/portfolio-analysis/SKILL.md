# 資産の棚卸しと集計

## いつ使うか

- 資産の現状把握、内訳の集計、純資産の計算
- リバランスやリスク分析の前段のデータ整備

## 手順

1. 口座の網羅を確認する。銀行、証券、iDeCo、保険、ポイント、不動産、負債。
2. 1 行 1 保有の表を作る。列は次を標準とする。
   `口座 / 商品名 / コード / 資産クラス / 通貨 / 数量 / 取得額 / 評価額 / 口座区分 / 年間コスト`
3. 資産クラスを分類する。現金・預金 / 国内債券 / 海外債券 / 国内株式 / 海外株式 / REIT / コモディティ / 暗号資産 / 保険・年金 / その他。
4. 集計する。
   - 資産クラス別・通貨別・口座区分別の評価額と比率
   - 純資産 = 総資産 - 負債
   - 上位 5 銘柄の合計比率
   - 年間コスト合計と資産比
   - 生活防衛資金として使える流動性 (現金・預金のうち使う予定のない部分)
5. 保存する。`data/portfolio-YYYY-MM-DD.xlsx` を基準日にちなんで作り、集計シートと明細シートを分ける。

## 実装のコツ

- 明細 CSV は `xlsx` skill で読み、列名の揺れ (「評価額」「時価」) を吸収する。
- 集計は数式 (SUMIF, XLOOKUP) で残す。ハードコードした数字だけの表を作らない。
- 為替は評価日のレートと出典を記録する。円換算の方法 (TTS/TTB/仲値) を統一する。
- 大量明細の整理はサブエージェントに委任し、検算済みの集計だけ primary に戻す。

## 注意

- 個人データは `data/` にのみ書く。会話に残高を大量に貼らない。
- 分類に迷う商品 (毎月分配型、ヘッジ付き、複合型) は注記してユーザーに確認する。勝手に分類しない。
- 評価額は時点で変わる。基準日と出典を必ず添える。
