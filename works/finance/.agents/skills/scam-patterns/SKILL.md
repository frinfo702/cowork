# 投資詐欺のパターンと検証

## 危険サイン

- 元本保証、必ず儲かる、高利回り (年 10% 超を安全と主張)、損失補填の約束
- 未公開株、社債、海外 FX、暗号資産、AI 自動売買、副業、情報商材
- 紹介制・クローズドなグループ、講師を「先生」と呼ばせる、成功者の体験談
- 出金を止める、追加送金・コンサル料・税関費用を要求する
- 公的機関・有名企業・著名人の名前を無断で使う
- 急かす (期間限定、今日中)、一人で判断させない、家族に言うな
- 本人確認をしない、契約書を渡さない、振込先が個人名義・海外

## 検証手順

1. 業者の登録を確認する。
   - 金融庁 登録業者検索 (金融商品取引業者、投資助言・代理業)
   - 財務局の免許・許可一覧
   - 日本証券業協会の会員検索、日本投資顧問業協会
2. 商品の実在を確認する。未公開株は会社の登記、有価証券報告書、事業実態を確認する。
3. 相手の主張を「事実」「出典不明」「虚偽の可能性」に分類する。出典を示せない主張は危険サインとして扱う。
4. 送金前なら止める。国内振込・暗号資産送付・ギフトカード・現金書留はすべて対象。

## 相談・通報先

- 消費者ホットライン 188 (最寄りの消費生活センター)
- 警察相談専用電話 #9110 (緊急時は 110)
- 金融庁 相談ダイヤル 0570-016811
- 日本証券業協会 投資相談 (無登録業者に関する相談)

## 二次被害への注意

- 一度個人情報を渡すと、名簿に載り別の勧誘が来る。
- 「返金します」という連絡も詐欺の手口 (回収詐欺)。返金を名目に送金させない。
- クレジットカード、銀行口座、マイナンバーの情報を渡していないか確認する。
