# 論文の解剖

## 読む順序

1. abstract と結論: 何を主張しているか。数字はあるか。
2. 図表: 主張を一番よく表す図。軸、比較対象、エラーバーを確認する。
3. introduction: 問題、なぜ難しいか、貢献のリスト。
4. method: 再現できる粒度か。数式の記号は定義されているか。
5. experiments: 設定、baseline、指標、ablation、統計。
6. related work: 差分の主張。
7. 付録とコード: 実装の細部、ハイパーパラメータ、データ処理。

## 検証チェックリスト

- baseline は強いか。最新か、チューニングされているか
- データ分割にリークはないか。test を探索に使っていないか
- 指標は主張に適切か。計算コストは公平か
- seed とばらつき。単一 run か
- 統計処理。検定、信頼区間、多重比較
- ablation は主張を切り分けているか
- 再現に必要な情報 (コード、データ、ハイパーパラメータ) があるか

## メモのテンプレート

```
# <title>
- 書誌: authors / venue / year / arXiv / DOI / 確認日
- 主張: 一文
- 方法: 要点 3 つ
- 証拠: dataset / baseline / metric / 数値 / seed / 統計
- 限界: 著者の記載 / 自分の指摘
- 関連: 最も近い論文と差分
- 自研究への含意: 使える / 比較すべき / 再現すべき
- 検証状態: 原典確認済み / 未確認
```

## 注意

- 要約に自分の評価を混ぜない。評価は別セクションに分ける。
- abstract の数字は本文と一致するか確認する。改訂版で変わる場合がある。
- 引用可能な形 (arXiv ID、DOI) を必ず記録する。存在しない文献を書かない。
