# playbook: result-analysis — 結果の分析・統計

## 目的

結果を誇張せず、ばらつきと不確実性を含めて解釈する。単一 run の結論を避ける。

## 手順

1. 生データを確認する。run 数、seed、失敗した run、除外した run とその理由。
2. 要約する。平均、標準偏差、中央値、信頼区間。外れ値の扱いを明示する。
3. 比較する。baseline との差、効果量、検定 (`skills/experiment-methodology`)。多重比較を補正する。
4. 学習曲線を見る。改善が途中で止まっていないか、まだ伸びるか、計算量を揃えて比較しているか。
5. ablation の結果を整理する。どの要素がどの程度寄与したか。交互作用を確認する。
6. 想定外の結果を歓迎する。失敗 run を隠さない。原因の仮説を書く。
7. 主張との整合を確認する。結果が支持する主張と、支持しない主張を分ける。
8. 再現性の情報を添える。seed、環境、計算資源、コード版。
9. グラフを作る。軸、単位、エラーバー、凡例を明確に。`xlsx` や matplotlib を使う。

## 使う skills

- `skills/experiment-methodology`
- `skills/research-ethics`

## 出力

- 結果表 (平均 ± 標準偏差、n、検定結果)
- グラフ (学習曲線、比較、ablation)
- 解釈と限界
- 追加で必要な実験

## 承認・エスカレーション

`approval: none`。p 値だけに依存しない。効果量と実用上の意味を併記する。有意でない差を「傾向がある」と言い換えない。
