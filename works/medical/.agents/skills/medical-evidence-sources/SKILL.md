# 医療情報の情報源

## 信頼できる情報源

- 厚生労働省 https://www.mhlw.go.jp/ (政策、検診、感染症、難病)
- 国立健康・栄養研究所 (健康食品の安全性・有効性情報) https://hfnet.nibiohn.go.jp/
- PMDA (電子添文、副作用情報) https://www.pmda.go.jp/
- 国立がん研究センター がん情報サービス https://ganjoho.jp/
- 日本医学会、各学会の診療ガイドライン (Minds https://minds.jcqhc.or.jp/)
- Cochrane (システマティックレビュー)
- MSDマニュアル 家庭版・プロフェッショナル版
- 自治体の保健所・保健センター

## 避ける情報源

- 検索結果の広告、アフィリエイト目的のまとめサイト
- 個人の体験談を根拠にする主張
- 効果を保証するサプリ・健康食品の宣伝
- 出典のない「医師が監修」表記

## 根拠の強さ

1. システマティックレビュー・メタアナリシス
2. ランダム化比較試験
3. コホート研究、症例対照研究
4. 症例報告、専門家の意見

強い根拠がない話題では「わかっていない」と正直に書く。

## 引用の作法

- 出典名、発行機関、年、URL、確認日を書く。
- 一般向け情報と、診療ガイドラインの推奨を区別する。
- 個人の症状に当てはめる場合は「一般には〜とされている」と但し書きを付ける。

## 注意

- 医学知識は更新が速い。記憶で数値や基準を語らない。
- ガイドラインの推奨は対象集団の話。個別の判断は診察した医師が行う。
