# playbook: test-results — 検査結果・健診の理解

## 目的

検査値の意味、基準値の考え方、再検査の必要性を整理する。単独の数値で診断しない。

## 手順

1. 検査の種類と目的を確認する。血液検査、尿検査、画像、心電図、腫瘍マーカー。
2. 数値を表にする。項目、値、基準値、前回値、変化。`xlsx` skill で推移グラフを作る (`skills/health-records`)。
3. 基準値の前提を確認する。年齢、性別、妊娠、施設ごとの基準、測定法。
4. 各項目の意味を一般情報として説明する (`skills/medical-evidence-sources`)。断定や病名の提示はしない。
5. 判定区分を確認する。要精密検査、要再検査、要治療、経過観察。健診票に書かれた指示を最優先する。
6. 再検査・受診の時期を示す。放置した場合の一般論ではなく、健診機関の指示と医師の判断に従うことを伝える。
7. 医師に聞く質問を作る。数値の意味、追加検査の必要性、生活への影響、経過観察の間隔。

## 使う skills

- `skills/medical-evidence-sources`
- `skills/health-records`
- `skills/safety-limits`

## 出力

- 検査値一覧 (値、基準値、前回比)
- 各項目の一般的な意味 (出典付き)
- 健診票の指示の要約
- 医師への質問リスト

## 承認・エスカレーション

`approval: none`。「異常なし」「心配ない」と断言しない。健診結果の最終判断は医療機関。
