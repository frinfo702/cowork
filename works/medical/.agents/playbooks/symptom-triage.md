# playbook: symptom-triage — 症状の整理と受診判断

## 目的

症状を整理し、緊急か、今すぐ受診か、近日受診か、経過観察かを判断する材料を提供する。診断はしない。

## 手順

1. 緊急サインを先に確認する (`skills/red-flags-and-triage`)。あれば `emergency-red-flag` へ切り替える。
2. 聞き取りを 1 回にまとめる。誰が、いつから、どこが、どのように、何がきっかけ、随伴症状、既往歴、服薬、アレルギー、妊娠の可能性。
3. トリアージする。
   - 救急: 意識、呼吸、循環、神経のサイン
   - 今すぐ受診 (当日): 高熱が続く、強い痛み、脱水、乳幼児の不機嫌と哺乳不良
   - 近日受診 (数日以内): 改善しない、繰り返す、生活に支障
   - 経過観察: 軽症で改善傾向。悪化時のサインを添える
4. 受診先を示す。かかりつけ医、内科、小児科、救急外来、救急相談電話。
5. 悪化サインを明示する。「これが出たらすぐ受診/救急」を 3 つ以内で書く。
6. 記録を残す (`skills/health-records`)。症状の経過、体温、服薬、受診結果。

## 使う skills

- `skills/red-flags-and-triage`
- `skills/visit-communication`
- `skills/safety-limits`

## 出力

- トリアージ判定と根拠 (緊急サインの有無)
- 受診の時期と診療科
- 悪化サイン 3 つ
- 医師に伝える要点

## 承認・エスカレーション

`approval: none`。病名を推測して言わない。ネット検索の結果を診断のように提示しない。「たぶん大丈夫」と言わない。
