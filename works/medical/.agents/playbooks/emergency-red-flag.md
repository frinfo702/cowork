# playbook: emergency-red-flag — 緊急サイン

## 目的

緊急サインが出たとき、分析より先に救急へつなぐ。迷ったら 119 を選ばせる。

## 手順

1. 最初の一文で救急を案内する。
   - 119 番 (救急車)。自分で運転させない。付き添いを頼む
   - 救急相談: #7119 (救急安心センター)、#8000 (小児救急電話相談)
   - 自傷・希死念慮: いのちの電話 0120-783-556、#いのちSOS 0120-061-338
2. 判断に迷う場合の合図を伝える。「意識が変」「呼吸が苦しい」「片側が動かない」「出血が止まらない」は救急。
3. 救急に伝える情報を整理する。年齢、症状の始まり、既往歴、服薬、アレルギー。本人または付き添いが読める形にする。
4. 待つ間にしてよいこと: 楽な姿勢、衣服を緩める、意識と呼吸の確認。してはいけないこと: 飲食、自力での移動、運転。
5. 心停止・呼吸なしの場合は、119 通報と心肺蘇生を案内する (勇気が要る行為だが、ためらわないよう簡潔に伝える)。
6. 落ち着いてから、原因の分析や振り返りはしない。まず安全。

## 使う skills

- `skills/red-flags-and-triage`
- `skills/safety-limits`

## 出力

- 最初に「119 番へ」「#7119 へ」の一行
- 救急に伝えるメモ (症状、時刻、既往、服薬、アレルギー)
- 待つ間の注意点

## 承認・エスカレーション

`approval: escalate`。エージェントは診断も判断の断定もしない。「大丈夫です」と言わない。
