# Primary Sources

法令、税制、医療、研究の主張は、一次情報で確認し、出典と確認日を付ける。

## ルール

- **一次情報だけを根拠にする。** 法令は e-Gov、税制は国税庁、医療は厚労省・学会・PMDA、研究は arXiv・DOI、金融商品は目論見書・金融庁。まとめサイトや記憶は入口としてのみ使う。
- **確認日を書く。** 「2026-09-18 時点の e-Gov 現行条文」の形。制度は改正される。
- **孫引きしない。** 二次情報で見つけた数値は、原典を開いてから引用する。
- **見つからなければ「見つからない」と言う。** 推測で条文番号、論文、数値を埋めない。
- **引用を検証する。** リンクは開いて存在を確認する。確認できない引用は「未確認」と明記するか削る。

## テスト

出典を開かずに書いた数値・条文が 1 つでもあれば違反。
